# Tests

This directory contains testing plans and future automated tests for the project.

## Testing Scope

The project will include tests for:

- API functionality
- Program Catalog data
- Client-side behaviour
- Accessibility
- Integration between client and server

## Accessibility Testing

Accessibility testing will include:

- Keyboard-only navigation
- Heading hierarchy
- Color contrast
- Image alternative text
- Focus indicators
- Interactive element accessibility
- HTML landmarks

## Planned Test Strategy

Tests will be added as the client and server features are implemented.

The first test focus will be the Program Catalog feature and its client-server integration.
