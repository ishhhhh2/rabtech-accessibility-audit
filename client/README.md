# Client

This directory contains the frontend application.

## Responsibilities

- User interface and page layouts
- Reusable UI components
- Client-side interactions
- Accessibility
- Communication with backend APIs

## Planned Technology

- React
- Tailwind CSS
- JavaScript

## Planned Feature

The first vertical feature slice will be the Program Catalog.

The client will request program data from the server API and display the programs in an accessible user interface.
